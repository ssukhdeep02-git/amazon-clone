# Amazon Clone

A clone of the Amazon homepage that I built using only HTML and CSS. I made it to practice page layout and get better at turning a real website design into code.

![Screenshot](images/screenshot.png)

## What's in it

- Navbar with the logo, delivery location, search bar, sign in, returns and cart
- Secondary panel with links like Today's Deals and Customer Service
- Hero banner with the "You are on amazon.com" message
- 8 product category boxes (Clothes, Furniture, Electronics, Pet Care, Toys and more)
- Footer with 4 link columns, the logo and the copyright line

## Built with

- HTML5
- CSS3 (flexbox for most of the layout)
- Font Awesome for the icons

No JavaScript, no frameworks.

## How to run it

1. Clone the repo
   ```
   git clone https://github.com/ssukhdeep02-git/amazon-clone.git
   ```
2. Open the folder and double click `index.html`

That's it, it opens in any browser. You need internet once so the Font Awesome icons load.
